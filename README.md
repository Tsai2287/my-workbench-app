# 我的工作台 🌏

一個為 iPhone 設計的行動工作台，左側清單包含四個模組：

| 模組 | 用途 |
|------|------|
| 🇰🇷 韓文學習 | TOPIK 導向的階段化清單（發音→詞彙→文法→聽說→應考求職），強調「開口說」 |
| 🧳 行李檢查 | 韓國 / 日本出行清單，可切目的地與天數，自動調整衣物數量建議 |
| 🌫️ 城市迷霧 | 記錄去過的國家/城市 + 當地照片，解鎖式「撥開迷霧」效果 |
| 📖 讀書記錄 | 記錄看完的小說與心得感想 |

所有資料**只存在你手機瀏覽器本地**，不上傳任何伺服器。

## 在 iPhone 上使用

1. 把這個資料夾放到任意可存取的地方（如 GitHub Pages / Netlify / 自己的空間），用手機 Safari 打開 `index.html`。
2. 點 Safari 底部的「分享」→「加入主畫面」，即可像 App 一樣從主畫面打開，全螢幕無網址列。
3. 離線也能用（PWA 已配置）。

## 換手機 / 備份

- 左側底部有 **⬇️ 匯出備份**（產生一個 JSON 檔），換手機時用 **⬆️ 匯入備份** 還原即可，足跡、照片、讀書紀錄全部保留。
- 城市迷霧的照片會以壓縮形式存在本地；從相簿選圖時會**自動讀取照片的 GPS 定位**填入地點（若照片本身帶定位）。無定位則手動填國家/城市。

## 檔案說明

- `index.html` — 主頁面與樣式
- `app.js` — 框架、資料儲存、匯出/匯入
- `modules.js` — 四個模組的內容與互動邏輯
- `manifest.webmanifest` / `icon-*.png` — PWA 設定與圖示

## 小提醒

- iOS Safari 無法直接讀取整個相簿或自動擷取照片 GPS，需手動選圖；有定位的照片會自動填地點。
- 想永久保留跨裝置同步，最穩妥仍是定期「匯出備份」並存到雲端（如 iCloud/隨身碟）。
